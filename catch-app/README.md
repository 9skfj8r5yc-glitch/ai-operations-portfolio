# Catch App — AI Fishing Forecaster

Live at **catchapp.com**.

Zero-dependency single-file web app (`index.html`, ~42KB): NOAA/NWS + USGS APIs, custom solunar/sun engine, evidence-weighted scoring, all 50 states + custom spots, pond scanner, labeled training-data logging and CSV/JSON export, shareable forecast links.

Full source is being pushed via authenticated git (file exceeds plugin API inline limits). Until then, the production copy runs at catchapp.com.
